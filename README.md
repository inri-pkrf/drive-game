# מתניעים אחריות — מפצחים את קוד הבטיחות

משחק מגע אנכי (1080×1920) לטוטם בשבוע הבטיחות בדרכים. כל הממשק בעברית ומימין לשמאל.

## מבנה הפרויקט
- `index.html` — מבנה המסכים
- `css/style.css` — עיצוב (כותרות Karantina, שאר הטקסט Assistant)
- `js/questions.js` — מאגר השאלות (כל שאלה עם הסבר וכתובת מקור ברלב"ד)
- `js/game.js` — לוגיקת המשחק, קוד אקראי, מקלדת עברית, צלילים ודירוג
- `assets/bg.jpg` — צילום תא הנהג (רקע), `assets/drive.mp4` — סרטון הנסיעה (מחליף את הרקע אחרי קוד נכון), `assets/logo.png` — לוגו המכללה
- `server.js` — שרת קטן (ללא התקנת חבילות) שמגיש את המשחק ושומר דירוג משותף ב-`data/scores.json`

## הרצה (נדרש Node.js 16 ומעלה)
1. פתחו את התיקייה ב-Visual Studio Code (`File > Open Folder`).
2. פתחו טרמינל (`Terminal > New Terminal`) והריצו: `npm start`
3. פתחו בדפדפן את http://localhost:3000

אין שלב build ואין `npm install`.

## לוח תוצאות משותף לכל הטוטמים
הריצו את השרת על מחשב אחד ברשת המכללה, ופתחו בכל טוטם את `http://<כתובת-המחשב>:3000`. כל התוצאות נשמרות באותו קובץ. אם פותחים את `index.html` ישירות (בלי שרת), הדירוג נשמר רק בדפדפן המקומי, והמסך מציין זאת.
לתצוגת קיוסק אפשר להריץ: `chrome --kiosk http://<כתובת-המחשב>:3000`. יש כפתור מסך מלא בפינה השמאלית העליונה.

## עריכה
- שאלות: ערכו את `js/questions.js`. המבנה: `[נושא, תרחיש, תשובה נכונה, [שלוש שגויות], הסבר, מקור]`. לפני שמוסיפים שאלה יש לאמת אותה מול מקור רשמי.
- תשובה שגויה מסומנת באדום, הנכונה בירוק עם הסבר, ואחרי 3 שניות מגיעה שאלה חדשה. ספרת קוד נחשפת רק על תשובה נכונה, ולכן צריך ארבע תשובות נכונות. הקוד הסודי הוא 4 ספרות מתוך 1–4 (ספרות יכולות לחזור). סדר השאלות והתשובות אקראי, והשאלות נמשכות משקית שנשמרת בדפדפן, כך שלא חוזרות על עצמן עד שכל המאגר נוצל.
- איפוס הדירוג: מחקו את `data/scores.json` כשהשרת כבוי.

## פונטים
הפונטים נטענים מ-Google Fonts ולכן נדרש אינטרנט. לשימוש לא מקוון הורידו את Karantina ואת Assistant לתיקייה `assets/fonts` והפעילו את בלוק `@font-face` שבסוף `css/style.css`.

## הערות
- צליל המנוע מסונתז באמצעות Web Audio. להקלטה אמיתית החליפו את הפונקציה `snd.engine` בנגן קובץ אודיו.
- אחרי קוד נכון הסרטון מחליף את הרקע ומתנגן עם הקול שלו (כפתור ההשתקה משתיק גם אותו), ואז ממשיך בלולאה שקטה עד האיפוס.
